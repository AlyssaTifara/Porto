Tentang Saya

Latar belakang, cara kerja, dan arah pengembangan profesional

Fokus Peran

Data Engineer Intern | Data Analyst Intern

Fokus utama: perancangan data pipeline, proses ETL, dan arsitektur skema relasional untuk memastikan data siap pakai, konsisten, dan dapat diandalkan dalam alur kerja operasional.

Fokus pendukung: analitik data, pengembangan dashboard BI, dan penyampaian insight yang ringkas agar hasil analisis dapat langsung mendukung pengambilan keputusan.

Latar Belakang

Saya mahasiswa Sistem Informasi Bisnis di Politeknik Negeri Malang dengan fokus pada data engineering dan analitik. Saya terbiasa merancang workflow ETL, menyusun desain skema relasional, dan melakukan transformasi data dengan Power Query agar data siap dianalisis secara konsisten.

Dalam proyek akademik dan operasional, saya mengolah dataset operasional nyata (500+ records) untuk menghasilkan insight melalui SQL, Python, dan dashboard BI, sekaligus mendokumentasikan alur data agar implementasi lebih terstruktur dan dapat direplikasi.

Pendekatan Kerja

Saya bekerja dengan pendekatan terstruktur dan berbasis analisis. Setiap masalah saya awali dengan memahami konteks, merumuskan kebutuhan, lalu mengolah data atau informasi yang relevan sebelum menarik kesimpulan.

Saya terbiasa mengomunikasikan hasil analisis dalam bentuk ringkas, jelas, dan mudah dipahami, terutama untuk audiens non-teknis, agar insight dapat digunakan sebagai dasar pengambilan keputusan.

Sikap Belajar & Pengembangan Diri

Saya memiliki growth mindset yang mendorong saya terus mengevaluasi hasil kerja, belajar dari feedback, dan meningkatkan kualitas solusi secara iteratif. Saya memprioritaskan pembelajaran yang mendalam agar setiap implementasi data lebih akurat, relevan, dan berdampak.
